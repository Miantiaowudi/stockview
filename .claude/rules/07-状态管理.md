# 状态管理规范

## 基础规范

- 状态管理使用 **Zustand**
- 所有 store 文件放在 `src/hooks/` 目录下（与 React Hooks 同级）
- **禁止在 `src` 下新建其他目录存放 store**

## Store 组织规范

- Store 按业务模块划分
- 每个模块暴露 `useXxxStore` Hook
- Store 只存纯数据与业务行为，不耦合 UI 组件

## 目录结构

```
src/hooks/
├── useUser.ts           # useUserStore
├── useTheme.ts          # useThemeStore
└── useStockAnalysis.ts  # useStockAnalysisStore
```

## 持久化（如需要）

使用 `zustand/middleware` 的 `persist` 持久化状态。
