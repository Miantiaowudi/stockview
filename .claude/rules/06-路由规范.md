# 路由规范

## Next.js App Router 结构

- 页面目录在 `src/app/` 下
- 使用目录结构定义路由
- `page.tsx` 是页面入口，`layout.tsx` 是布局
- 使用 `loading.tsx` 做加载状态

## 路由目录

| 目录 | 路由 | 说明 |
|------|------|------|
| `src/app/` | `/` | 首页 |
| `src/app/auth/` | `/auth` | 认证 |
| `src/app/dashboard/` | `/dashboard` | 仪表盘 |
| `src/app/dashboard/detail/[code]/` | `/dashboard/detail/:code` | 个股详情 |
| `src/app/dashboard/import/` | `/dashboard/import` | 数据导入 |

## 动态路由

使用 `[param]` 语法：

```
src/app/dashboard/detail/[code]/page.tsx  →  /dashboard/detail/:code
```

## 布局规范

- `layout.tsx` 定义共享布局
- 子页面自动继承父布局
- 使用 `template.tsx` 做需要重渲染的布局

## 路由与菜单

- 全局路由配置集中管理
- 禁止多处维护路由配置
