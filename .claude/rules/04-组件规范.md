# 组件规范

## 组件结构

- 组件文件使用 PascalCase: `StockCard.tsx`
- 组件放在 `src/components/`（通用）或页面目录的 `components/`（页面专用）
- 所有组件必须使用清晰的 TS 类型定义，Props 接口必须明确
- 使用 `'use client'` 标记客户端组件

## 样式规范

- 使用 Tailwind CSS 原子化类名
- 复杂样式用 CSS 变量（定义在 `globals.css`）
- `classnames` 负责动态 class 管理

## 组件层级规划

- 单个 `.tsx` 文件建议不超过 400 行
- 遵循单一职责原则
- **页面级组件**：仅在当前页面使用 → 放在 `src/app/<page>/components/`
- **通用组件**：跨页面复用 → 提取到 `src/components/`

## 组件放置决策树

```
组件需要在多个页面使用吗？
├─ YES → 通用组件 → 放在 `src/components/<name>/`
└─ NO → 仅在单页使用 → 放在 `src/app/<page>/components/<name>/`
```

**示例**：

- `ErrorBoundary`（多处使用）→ `src/components/error-boundary/`
- `StockChart`（仅详情页使用）→ `src/app/dashboard/detail/[code]/components/`

## 约束

- `src/components/` 只存放通用组件
- 客户端组件添加 `'use client'`
- 使用 ErrorBoundary 包装页面
