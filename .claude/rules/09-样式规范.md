# 样式规范

## 基础原则

- 使用 Tailwind CSS 原子化类名
- 复杂样式用 CSS 变量（定义在 `globals.css`）
- `classnames` 负责动态 class 管理

## CSS 变量

在 `globals.css` 中定义复杂样式变量：

```css
:root {
  --primary-color: #1890ff;
  --border-radius: 8px;
}
```

## Ant Design 主题色

使用 Ant Design 提供的主题变量：

- `var(--ant-color-primary)`
- `var(--ant-color-text)`
- `var(--ant-color-bg-container)`

## Tailwind CSS 使用

```tsx
// 基础用法
<div className="flex items-center justify-between p-4">

// 条件类名
<div className={cn(
  'base-class',
  isActive && 'active-class'
)}>
```

## 设计稿颜色提取

| 属性 | 含义 |
|------|------|
| `fill` | 背景色 |
| `stroke` | 边框色 |
| `opacity` | 透明度 |
