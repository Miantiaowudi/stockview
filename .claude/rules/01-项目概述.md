# 项目概述

## 项目定位

基于 Next.js 16 + AI 的股票分析平台，支持交易记录管理、K线查看、AI 智能分析。

## 技术栈

| 领域 | 技术 | 说明 |
|------|------|------|
| 框架 | Next.js 16 | App Router |
| UI 框架 | React 19 | 强制使用 |
| 类型系统 | TypeScript 5.x | 强制使用，禁止 JavaScript |
| 组件库 | Ant Design 6 | 所有交互 UI 基于 Antd |
| 样式方案 | Tailwind CSS 4 | 原子化类名优先 |
| 数据库 | Supabase | PostgreSQL + Auth |
| AI | LangGraph + DashScope | qwen-plus 模型 |
| 图表 | Recharts, ECharts, Lightweight Charts | - |
| 状态管理 | Zustand | 跨组件状态共享 |
| Hooks 工具 | ahooks | 优先使用已有的 ahooks |
| 时间工具 | dayjs | 日期时间处理 |
